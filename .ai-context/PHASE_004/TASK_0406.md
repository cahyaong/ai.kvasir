## 2. Problem

All creatures are currently destroyed when they receive lethal damage (SBA Rule 704.5g). Indestructible (Rule 702.12) prevents destruction from any source — lethal damage, deathtouch, and destroy effects all fail. The creature still receives damage (relevant for lifelink, trample assignment) but is not destroyed by it.

## 3. Acceptance Criteria

- [ ] A creature with indestructible is not destroyed by lethal damage (SBA 704.5g skips it)
- [ ] A creature with indestructible is not destroyed by deathtouch (SBA 704.5h skips it)
- [ ] Damage is still dealt and marked on an indestructible creature (lifelink triggers, damage tracking works)
- [ ] Trample vs indestructible: lethal must still be assigned to the blocker, excess tramples (blocker survives)
- [ ] Indestructible does NOT prevent: sacrifice, exile, -X/-X reducing toughness to 0 (SBA 704.5f — separate rule)
- [ ] Unit test: 5/5 indestructible takes 10 damage — survives, has 10 damage marked
- [ ] Unit test: 1/1 deathtouch vs 2/2 indestructible — indestructible survives, 1/1 dies
- [ ] Unit test: 7/7 trample blocked by 2/2 indestructible — assign 2 (lethal), trample 5, blocker survives

## 4. Implementation Guidance

- In SBA handler (Rule 704.5g): before destroying for lethal damage, check `HasKeyword(KeywordAbility.Indestructible)` — skip if true
- In SBA handler (Rule 704.5h): before destroying for deathtouch, check indestructible — skip if true
- Do NOT modify damage assignment for trample: indestructible doesn't change what's considered "lethal" for assignment. Assign toughness-worth, it just doesn't kill the blocker.
- Note: 0 toughness (704.5f) still kills indestructible creatures — that's not destruction, it's a separate SBA
