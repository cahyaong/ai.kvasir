## 2. Problem

Spells on the stack cannot yet target anything, so removal ("destroy target creature"), burn ("deal 3 damage to target creature"), and combat tricks are impossible. This task implements single-target selection at cast time and legality re-checking at resolution (Rule 115, Rule 608.2b), which unlocks the bulk of interactive one-target spells. Multi-target and partial-fizzle handling is `TASK_0305`.

## 3. Acceptance Criteria

- [ ] A spell/ability with one target has its target chosen when it is put on the stack (Rule 601.2c)
- [ ] Target legality is validated at cast time against the target's restriction (e.g., "target creature", "target player")
- [ ] Each distinct legal target is a distinct action in `GetLegalActions()` (feeds the action space for AI)
- [ ] At resolution, the single target is re-checked for legality (Rule 608.2b)
- [ ] If the sole target is illegal at resolution, the spell fizzles: it does not resolve and goes to the graveyard (ability ceases)
- [ ] A spell whose target left the battlefield / changed zones between cast and resolution correctly fizzles
- [ ] Unit test: "destroy target creature" destroys the chosen creature on resolution
- [ ] Unit test: target creature removed in response → spell fizzles, no effect, spell in graveyard

## 4. Implementation Guidance

- Fill the target placeholder on `StackObject` (from `TASK_0301`) with a resolved target reference chosen at cast time.
- Model a target descriptor (what a spell may target) and a legality predicate that filters candidate targets. The card's parsed effect text carries the target restriction.
- Populate the resolution seam left by `TASK_0302`: before following instructions, re-check the target; on illegal-target, fizzle per Rule 608.2b.
- Enumerate one action per legal target at the priority hold. Note the action-space growth documented in `DESIGN_Engine_InteractionLayer.md` §5.1 (mitigations are a Phase 8 AI concern, not here).
- Add canonical single-target cards as YAML: a removal spell (e.g., Murder / Doom Blade style) and a burn spell (e.g., Lightning Strike).
- Key rules: RX-115, RX-601.2c, RX-608.2b.
