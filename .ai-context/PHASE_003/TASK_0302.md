## 2. Problem

`TASK_0301` builds a stack that can be pushed to but never resolves. This task implements resolution: when all players pass in succession with a non-empty stack, the top object resolves, follows its instructions, and moves to the correct zone (Rule 405.5, Rule 608). Without this, a cast spell sits on the stack forever.

Targeting legality at resolution (fizzle) is deferred to `TASK_0304` — this task resolves non-targeted objects and provides the resolution hook where the target check will slot in.

## 3. Acceptance Criteria

- [ ] All players passing in succession with a non-empty stack resolves the top object (Rule 405.5)
- [ ] After a resolution, the active player receives priority again (feeds the `TASK_0104` loop)
- [ ] An instant or sorcery goes to its owner's graveyard after resolving (Rule 608.2m)
- [ ] A permanent spell enters the battlefield after resolving
- [ ] An ability ceases to exist after resolving
- [ ] A non-targeted effect (e.g., "each player draws a card", "you gain 3 life") executes correctly on resolution
- [ ] The resolution procedure exposes a hook point for the target-legality check added in `TASK_0304`
- [ ] Unit test: a non-targeted instant resolves, applies its effect, and lands in the graveyard
- [ ] Unit test: a creature spell resolves onto the battlefield

## 4. Implementation Guidance

- Implement a resolve step that pops the top `StackObject`, dispatches to its effect handler, then performs the zone transfer based on object type (instant/sorcery → graveyard, permanent → battlefield, ability → cease).
- Wire the "all passed, stack non-empty → resolve" transition from the `TASK_0104` state machine (`RESOLVING → PROCESSING_SBAS → GRANTING_PRIORITY(active)`).
- Reuse the existing effect-handler pattern (Actions/Costs/Effects handlers) for the instruction-following step.
- Leave a documented seam in the pop procedure for target legality (Rule 608.2b) — `TASK_0304` fills it. For now, assume all objects have legal (or no) targets.
- Key rules: RX-405.5, RX-608.2, RX-608.3.
