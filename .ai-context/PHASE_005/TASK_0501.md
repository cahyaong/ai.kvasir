## 2. Problem

All creatures can currently be declared as attackers. Defender (Rule 702.3) prevents a creature from attacking. This is the simplest keyword — a pure restriction with no complex interactions.

## 3. Acceptance Criteria

- [ ] A creature with defender cannot be declared as an attacker
- [ ] A creature with defender can still block normally
- [ ] `IStrategy.DecideAttackers()` does not receive defender creatures as attack candidates
- [ ] A creature without defender can attack as normal (no regression)
- [ ] Unit test: defender creature cannot attack
- [ ] Unit test: defender creature can block

## 4. Implementation Guidance

- In the attack legality check, filter out creatures with `HasKeyword(KeywordAbility.Defender)`
- This is a simple exclusion filter — one conditional
- No interactions with other keywords (defender + flying just means it can block flyers but can't attack)

## 5. Files to Modify

- `Source/Kvasir.Engine/` (attack legality — exclude defender creatures)
- `Source/Kvasir.Engine.UnitTest/` (defender tests)
- Card definitions: add a defender creature (e.g., Wall of Omens, Steel Wall)
