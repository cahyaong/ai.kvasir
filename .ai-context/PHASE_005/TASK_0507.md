## 2. Problem

The current card pool contains only vanilla creatures and basic lands. With keyword abilities implemented, the engine needs a diverse set of keyword creatures to validate full-game interactions and generate meaningful training data for Phase 8 AI strategies. The card pool should cover all 12 keywords across different color identities and mana costs.

## 3. Acceptance Criteria

- [ ] 20-30 keyword creatures added to card definitions (YAML)
- [ ] Every keyword is represented by at least 2 creatures
- [ ] Multi-keyword creatures included (e.g., flying + vigilance, deathtouch + lifelink)
- [ ] Mana curve distribution: 1-6 CMC represented
- [ ] All five colors represented
- [ ] Full integration test: complete game with keyword creatures produces valid game state
- [ ] No parsing errors: all new cards parse correctly through ANTLR pipeline
- [ ] `RandomStrategy` can play a full game with keyword creatures without crashing

## 4. Implementation Guidance

Suggested card pool (iconic, rules-simple, good test coverage):

| Keyword        | Candidates                                      |

| Lifelink       | Ajani's Pridemate (static only), Child of Night |
| Haste          | Goblin Guide, Lightning Mauler                  |
| Vigilance      | Serra Angel (shared), Tundra Wolves             |
| Menace         | Boggart Brute, Goblin War Party                 |
| Defender       | Steel Wall, Wall of Omens (no ETB)              |
| Indestructible | Darksteel Myr, Hazoret (simplified)             |

Multi-keyword highlights:
- Vampire Nighthawk: flying + deathtouch + lifelink
- Serra Angel: flying + vigilance
- Goblin Guide: haste (simple but iconic)

Process:
1. Fetch card data from Scryfall for each candidate
2. Create YAML definitions in the card definition format
3. Run full parse pipeline to validate
4. Run integration test: 2-player game with mixed keyword decks
