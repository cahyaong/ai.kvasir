## 2. Problem

`ExperimentSimulator.SimulateGame()` generates seeds using `(int)DateTime.UtcNow.Ticks`. Games started within the same tick receive identical seeds, producing duplicate results in batch experiments. This breaks reproducibility.

```csharp
// Current (broken):
var seed = (int)DateTime.UtcNow.Ticks;
```

## 3. Acceptance Criteria

- [ ] `ExperimentSimulator` accepts a master seed in `ExperimentConfig`
- [ ] Each game receives a unique, deterministic child seed derived from the master seed + game index
- [ ] Running the same experiment config twice produces identical results
- [ ] Existing `GameSimulator` seeding behavior is unchanged (it already accepts a seed parameter)

## 4. Implementation Guidance

- Add a `Seed` property to `ExperimentConfig`
- In `ExperimentSimulator.Simulate()`, create a master `Random` from the config seed
- Derive per-game seeds: `masterRandom.Next()` or `masterSeed + index` (either works, former is more robust)
- Pass derived seed to `CreateGameSimulator(id, derivedSeed)`
