## 2. Problem

`GameSimulator.SetupPlayerZones()` has a TODO: "Implement proper mulligan for sub-rule 103.4!" Currently, players always keep their opening hand of 7 cards with no mulligan option.

## 3. Acceptance Criteria

- [ ] London mulligan implemented per RX-103.4:
  - Player draws 7 cards
  - Player decides keep or mulligan (via `IStrategy`)
  - If mulligan: shuffle hand into library, draw 7 again, repeat decision
  - After keeping: bottom N cards (where N = number of mulligans taken)
- [ ] `IStrategy` has a new method for mulligan decisions (keep/mull + which cards to bottom)
- [ ] `RandomStrategy` implements a basic mulligan heuristic (e.g., mull hands with 0-1 or 6-7 lands)
- [ ] Mulligan count is tracked and accessible for experiment metrics
