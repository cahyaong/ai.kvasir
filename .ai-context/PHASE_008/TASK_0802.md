## 2. Problem

`IObserver` today is `ObserveStateChanged(ITabletop)` — a coarse per-phase pull of the whole board, defaulting to a no-op observer, and the only human trace is the flat `ExecutionResult.Messages` strings. This task makes the typed event stream from `TASK_0801` the single canonical trace: the engine emits events, observers subscribe, and one sink writes append-only JSONL. This is the observability payoff and the substrate that seed-replay (`TASK_0803`) validates against.

## 3. Acceptance Criteria

- [ ] `IObserver` is redesigned to observe a game event, replacing `ObserveStateChanged`
- [ ] `GameJudge` and `GameSimulator` setup emit the decision and outcome events at their existing chokepoints
- [ ] A composite observer fans out to multiple observers
- [ ] A JSONL sink observer writes one event per line to a configurable stream or path
- [ ] The existing debugging observer (console stepper) is adapted to consume events, using the state-snapshot event for its whole-board view
- [ ] Only the `ExecutionResult.Messages` payload is removed (messages derive from events via the `TASK_0801` formatter); `ExecutionResult` keeps its control-flow role — `IsTerminal`, `WinningPlayer`, and the `Create(...)` aggregation overloads stay
- [ ] Existing tests are updated; a test asserts the emitted event sequence for a scripted short game

## 4. Implementation Guidance

- Replace the `IObserver` method; update the no-op observer, the debugging observer, and the Autofac wiring in `AppBootstrapper` and `AutofacExtensions`.
- Emit at the points already calling `ObserveStateChanged` plus the finer decision sites (priority action, attackers, blockers, discard, zone moves, life and damage).
- Keep the JSONL sink dumb: serialize each event as a line, flush on write, no extra buffering semantics.
- Route `GameJudge` and `GameSimulator` result messages through the event formatter so nothing depends on `ExecutionResult.Messages`.
- Scope the `Messages` removal carefully: `ExecutionResult` and `GameResult` still drive turn/phase termination and the winner. Strip only the string payload and its aggregation, not the `IsTerminal`/`WinningPlayer` responsibilities.
- Whether the JSONL is persisted to disk by default or on demand is a `TASK_0803` concern (artifact tiering) — here just make the sink pluggable.
